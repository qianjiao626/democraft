# 数据与隐私说明

本说明描述 v0.1.0 的实现边界，不是安全认证。

## 数据去向

| 内容 | 存储或处理位置 |
| --- | --- |
| 导入的视频 | 原路径，只读取，不主动上传 |
| 新录屏 | Windows 视频目录下的 DemoCraft 子目录 |
| 手动保存工程 | 用户选择的 `.democraft` 文件 |
| 自动保存 | Electron userData 目录中的 `recovery.json` |
| 导出视频 | 用户选择的位置，编码过程中同目录生成临时 MP4 |
| 录制中的片段 | 暂存在内存，停止后写入文件 |

当前应用代码不包含账号登录、分析埋点、云上传或自动更新功能。安装开发依赖、下载发行版或安装 FFmpeg 需要通过相应工具联网，这与应用对素材的本地处理是不同的过程。操作系统、用户自行安装的软件和文件同步服务不在本项目控制范围内。

## 需要注意的权限

录屏可接触你选择的屏幕或窗口；麦克风可采集周围声音；系统音频可能包含其他应用的声音。只在必要时启用，结束后主动停止录制。不要录制未经授权的会议、账号信息或其他私密内容。

## 本地保存不等于加密

工程和自动保存记录是明文 JSON，可能包括本机绝对路径、标题和字幕。视频也不会由本应用加密。同一电脑上有权限访问文件的其他用户或程序可能读取它们。使用云同步文件夹会由同步软件处理文件，应用无法阻止这种行为。

## 管理数据

先关闭应用，再根据自己保存的位置检查录屏、工程、导出和恢复记录。删除恢复记录会失去对应恢复机会；不要在未备份重要工程时清理素材。卸载或删除应用文件夹不代表这些数据都被自动清除。

## 隐私遮挡的边界

遮挡是固定矩形，不自动识别个人信息、不追踪移动目标、不处理音轨。公开成片前人工检查全程；不要仅凭一次预览截图认定敏感信息已移除。
