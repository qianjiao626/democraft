# 发布前质量清单

[返回首页](../README.md) · [隐私说明](PRIVACY.md)

先导出短样片检查环境，再制作最终成片。本清单不是自动检测功能，也不替代授权或法律审查。

## 录制准备

- [ ] 展示内容已获得必要授权，使用虚构或已脱敏数据。
- [ ] 通知、聊天弹窗、密码管理器和无关窗口已妥善处理。
- [ ] 录制源选择正确；需要声音时已做短录制并试听。
- [ ] 鼠标移动与操作顺序已试走一遍。

## 画面可读性

- [ ] 在接近观众实际观看的尺寸下，关键文字仍能辨认。
- [ ] 主标题只表达一个主题，不靠过长文案补充所有信息。
- [ ] 聚焦进入、停留、退出均没有裁掉关键内容。
- [ ] 没有多余等待、错误输入或误导性的结果展示。
- [ ] 方形或竖屏构图经过实际检查，而不只是改了比例。

## 时间与音频

- [ ] 裁剪后首尾自然，结果留有阅读时间。
- [ ] 字幕与聚焦按原片时间设置，位置正确。
- [ ] 有声素材已试听导出文件，不只检查预览。
- [ ] 没有不应公开的对话、系统提示音或背景声音。

## 敏感信息与数据

- [ ] 从头到尾观看最终 MP4，而不只是检查截图。
- [ ] 遮挡覆盖全程有效，包括窗口移动和镜头缩放时。
- [ ] 未公开本机绝对路径、令牌、账号详情或客户数据。
- [ ] 分享工程前检查其明文内容，并确认素材可公开。

## 归档与反馈

- [ ] 原视频和工程都已保留，最终 MP4 可正常播放。
- [ ] 记录应用版本及必要的环境信息，便于复现问题。
- [ ] 反馈问题时仅提供最小脱敏样例，而非完整私人录屏。
