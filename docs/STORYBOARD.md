# 录制前脚本模板

[返回首页](../README.md) · [制作案例](RECIPES.md)

复制下面的模板到自己的笔记即可。它是创作准备清单，不是可导入的 `.democraft` 工程文件。

## 一页策划模板

```text
演示名称：
目标观众：
观众看完应理解的一件事：

需要展示的初始状态：
唯一的关键操作：
操作后的可见结果：

素材来源 / 授权情况：
是否使用虚构数据：
需要隐藏的信息：
是否需要声音：
预计原片时长：
画布比例：

顶部标签：
主标题：
唯一一条字幕：
字幕原片起止时间：
唯一一个聚焦区间：
聚焦对象：

工程保存位置：
源视频备份位置：
导出文件名：
```

## 简单分镜表

| 原片时间 | 观众看到什么 | 你执行什么 | 是否需要强调 |
| --- | --- | --- | --- |
| 0–__ 秒 | 初始状态 | 等待画面稳定 | 通常不放大 |
| __–__ 秒 | 核心操作 | 一次明确的输入或点击 | 选定一个聚焦区间 |
| __–__ 秒 | 结果状态 | 停留让观众阅读 | 回到正常比例 |

录完后再校准实际时间，不要机械使用录制前估算的时间点。裁剪时保留必要的上下文，否则观众可能只看到结果而不知道发生了什么。

## 文案写法示例

| 宽泛写法 | 更具体的写法 |
| --- | --- |
| 强大、高效、全新体验 | 一次筛选，找到本周待办 |
| 让工作更轻松 | 保存常用条件，减少重复输入 |
| 看看这个功能 | 点击导出，生成本地报告 |

以上仅是文案结构示例，不能用于宣称 DemoCraft 或其他软件拥有并未实现的功能。

## 推荐文件组织

```text
my-demo/
  source/          原视频，保留备份
  project/         手动保存的 .democraft 工程
  export/          最终 MP4
  notes/           脚本与校对记录
```

这种结构只是管理建议。当前工程使用源文件路径引用，不会因为文件放在同一上级目录就自动变成可迁移的打包工程。
