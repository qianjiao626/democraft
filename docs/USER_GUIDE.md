# 使用指南

[返回首页](../README.md) · [常见问题](FAQ.md)

## 1. 第一次运行

1. 从本仓库 Releases 下载 Windows x64 ZIP，完整解压后运行 `DemoCraft.exe`。
2. 查看左下角编码器状态。没有 FFmpeg 仍可尝试编辑预览，但无法导出 MP4。
3. 点击「先体验内置示例」。示例中的 Orbit 是虚构仪表盘，不是真实客户数据。
4. 尝试修改标题、选择背景，再导出一段短片，确认环境可用。

这是未签名预览版。不要关闭杀毒软件来绕过警告；先确认下载来源、校验文件与自己的运行风险。

## 2. 准备素材

### 导入视频

点击「导入本地视频」。文件选择器允许 MP4、WebM、MOV、MKV，但能否打开由实际视频编码决定，而不是扩展名。推荐 H.264 MP4 或 VP8/VP9 WebM。

导入新素材会建立新的编辑状态。替换素材前先保存重要工程。时长超过 5 分钟时，默认只选取前 5 分钟作为成片范围；你可以调整入点和出点。

### 录制窗口

1. 关闭通知，隐藏密码、令牌和个人信息。
2. 点击「录制屏幕 / 窗口」，在缩略图列表中选择来源。
3. 如需声音，**先勾选**麦克风或系统音频，再点击来源开始录制。
4. 完成后点击左侧「停止录制」。录屏会保存到 Windows 的视频文件夹下 `DemoCraft` 子目录。

录制最长 5 分钟。达到约 350MB 内存保护阈值时会主动停止，但这不是总内存占用上限。首次使用音频设备先录 10 秒并试听；选择了系统音频不代表驱动一定能采集到声音。

## 3. 裁剪与时间语义

底部拖动播放位置，点击「设为当前入点」或「设为当前出点」，也可直接输入秒数。

**所有字幕和镜头时间使用原始素材时间，而不是裁剪后的成片时间。**

例如原片长 40 秒，只保留 10–30 秒：

| 配置 | 原片时间 | 在成片中的位置 |
| --- | --- | --- |
| 裁剪范围 | 10–30 秒 | 0–20 秒 |
| 聚焦区间 | 14–18 秒 | 4–8 秒 |
| 字幕区间 | 12–22 秒 | 2–12 秒 |

成片时长必须大于 0 且不超过 300 秒。预览可定位到裁剪范围外检查素材，播放会受所选范围限制。

## 4. 画面设计

- **16:9**：产品演示、桌面教程，输出 1920×1080。
- **9:16**：竖屏分享，输出 1080×1920。
- **1:1**：方形预览，输出 1080×1080。

这三个选项改变画布比例，不会把横屏软件界面自动重排成竖屏。源视频保持比例放入画布；竖屏中桌面文字可能较小，需要自行选择合适的录制区域与聚焦点。

四款背景分别是晨雾、落日、薄荷、夜幕。主标题放在视频上方，顶部标签适合简短类别名称。长标题会缩小以适应画布，建议用一句短标题而不是整段介绍。

## 5. 镜头聚焦

开启右侧「镜头聚焦」，设置开始、结束、放大倍数及焦点 X / Y。

- 倍率范围 1–3 倍；1 倍没有放大效果。
- X / Y 为 0–1 的归一化位置，0.5 / 0.5 为中央，X 越大越靠右，Y 越大越靠下。
- 当前只支持一个区间，平滑进入并退出；结束时间应大于开始时间。
- 放大会裁掉部分画面，导出前检查按钮、文字是否仍在可见区域。

它是手动设置的镜头效果，不会检测点击事件，也不会自动追踪鼠标。

## 6. 字幕与隐私遮挡

底部字幕只有一条，设置原片中的起止时间。多句分段字幕、SRT 导入和语音识别尚未实现。

隐私遮挡是一个不透明矩形，位置和大小相对于源视频，随镜头一起缩放。它不会跟踪移动目标，也不会消除音频中的敏感信息。账号、通知或密码移动时，原位置的遮挡可能不再有效。

**发布前全程观看成片，尤其检查缩放进入、退出和窗口变化处。** 不要把功能开关当作隐私合规保证。

## 7. 保存和迁移

`.democraft` 工程保存编辑参数和源文件引用，**不是自带视频的归档包**。

- 保存工程不会修改原视频。
- 换电脑时同时复制工程与原素材；重开工程找不到素材时按提示重新定位。
- 自动保存只有一份恢复记录，不能替代多个工程的正式保存。
- 默认配置下恢复记录通常在 `%APPDATA%\democraft-studio\recovery.json`；以 Electron 实际 userData 目录为准。
- 工程可能包含本机绝对路径、标题和字幕；公开分享前检查是否泄露姓名、目录或内部信息。

## 8. 导出与发布检查单

点击「导出 MP4」，选择目标文件，等待逐帧处理完成。导出速度受分辨率、素材解码和 CPU 性能影响，可能慢于视频时长。需要停止时用导出对话框的取消按钮，不要强制终止程序。

发布前检查：

- [ ] 视频首尾、比例、时长符合预期。
- [ ] 关键操作清晰，聚焦没有裁掉必要信息。
- [ ] 字幕和标题无错字。
- [ ] 声音可听清，没有意外录入会议或其他软件声音。
- [ ] 所有敏感内容已人工检查。
- [ ] 素材、字体使用方式、音乐和展示内容具有适当授权。

本项目提供创作工具，不提供针对具体内容的法律审查结论。
