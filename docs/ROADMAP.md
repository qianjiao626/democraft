# 产品路线图

以下是方向建议，**不是已实现功能，也不是日期承诺**。优先根据真实使用反馈、可复现故障和测试能力调整。

## 当前：v0.1.0 Preview

已提供单视频录屏 / 导入、裁剪、画布设计、一个平滑聚焦区间、一条定时字幕、一个遮挡矩形、工程保存与 MP4 导出。验证范围见 [VERIFICATION.md](../VERIFICATION.md)。

## 优先级一：可靠性

- 在不同 Windows 设备上验证录屏、系统音频与麦克风组合。
- 覆盖完整 5 分钟录制和导出的内存、取消与异常恢复测试。
- 改善不支持编码、磁盘不足、素材移动时的提示。
- 改善自动保存恢复及工程迁移体验。

验收方向：失败不损坏原素材；取消不留误导性成片；重要错误有可执行的排查建议。

## 优先级二：更完整的演示编辑

- 多个聚焦区间和可视化时间线编辑。
- 多段字幕与字幕文件导入。
- 更直观的画面内焦点和遮挡位置调整。
- 模板复用和工程素材打包。

这些变化会涉及工程格式与交互设计，应先做兼容方案，再扩展功能数量。

## 后续评估：效率与分发

- 分析解码、PNG 传输与编码耗时，评估导出性能优化。
- 评估录屏分片落盘，减少内存占用。
- 根据维护资源评估签名、更新机制和更多平台。

暂不承诺 AI 自动剪辑、自动鼠标追踪、云协作或专业多轨工作流。若你需要这些功能，可以在 Issues 说明具体场景、现有操作成本与预期结果。
