# 常见问题与故障排查

[返回首页](../README.md) · [使用指南](USER_GUIDE.md)

## 提示找不到 FFmpeg

在新开的 PowerShell 中运行 `ffmpeg -version`。如果找不到命令，先安装并配置 PATH，再重新打开应用。也可设置 `DEMOCRAFT_FFMPEG` 为真实的可执行文件完整路径。仅在旧终端更新 PATH，已启动的桌面应用不会自动得到新环境。

## 检测显示就绪，但导出仍然失败

就绪检测只确认能运行 `ffmpeg -version`，不保证编码器齐全。检查 `ffmpeg -encoders` 是否包含 `libx264` 和 `aac`，同时确认目标文件夹可写、磁盘空间足够、源文件仍存在。先用内置示例导出 1 秒，区分环境故障与特定素材问题。

## MP4 / MOV 文件打不开，或者定位超时

容器与编码是两回事。可以将有使用权限的素材转为更常见的格式，输出到一个**新文件名**：

```powershell
ffmpeg -i "input.mov" -map 0:v:0 -map "0:a:0?" -c:v libx264 -pix_fmt yuv420p -c:a aac -movflags +faststart "converted.mp4"
```

该命令会重新编码，可能损失画质；保留原文件。不要直接改扩展名代替转换。

## 字幕没有出现，聚焦时间不对

使用的是原片绝对秒数。裁剪 10–30 秒后，字幕填 0–5 秒不会出现在成片中。检查字幕文本非空、起止区间覆盖当前播放时间；聚焦需要开启且结束大于开始。

## 为什么没有声音

先区分：源文件本来没有音轨，还是导出丢失了音轨。内置 Orbit 示例本来就是无声素材。录屏时必须在选择来源之前勾选音频选项；检查 Windows 麦克风权限和默认设备。系统音频采集受 Windows / Electron / 驱动支持限制，不能保证所有设备正常。

当前没有独立音量轨、降噪、音频设备选择器或配乐功能。不要把画面成功录制理解成音频也已验证成功。

## 导出为什么不是实时的

应用逐帧定位源视频，用统一 Canvas 渲染画面，再送入 FFmpeg 编码。这样预览和成片使用同一套视觉逻辑，但性能不等同于 GPU 专业剪辑软件。先导出短片验证，不提供固定倍速承诺。

## 保存了工程，为什么不能发给别人直接打开

工程不包含视频。请同时提供原素材；接收方打开时可能需要重新定位。文件中可能有你的本地路径和文案，分享前先检查。预览版不保证与未来所有工程格式永久兼容。

## 自动恢复找不到素材

确认原文件没有被删除或移动。目前只有正式打开工程提供重新定位流程，自动恢复没有。重要工作应主动另存工程，并保留素材备份。

## ZIP 解压后只有一个 EXE 能运行吗

不能只复制 EXE。Electron 所需资源、DLL 和 `resources` 文件夹必须保留。当前应用未签名，核对来源和发布页 SHA-256；不要通过关闭系统防护来解决未知来源问题。

```powershell
Get-FileHash -Algorithm SHA256 ".\DemoCraft-0.1.0-win.zip"
```

将结果与同一 Release 的 `SHA256SUMS.txt` 比较。哈希用于验证文件一致性，不等于安全审计。

## 如何反馈问题

在仓库 Issues 中提供：Windows 版本、应用版本、FFmpeg 版本、复现步骤、预期与实际结果，以及是否能用内置示例复现。只附脱敏截图或自行制作的最小样片，不上传客户数据、凭据、私密录屏或包含敏感内容的工程文件。
